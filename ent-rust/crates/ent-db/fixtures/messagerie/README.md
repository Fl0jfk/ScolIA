# Fichiers réels des tests de la messagerie (M5, M6)

Vrais PDF, vraies images, vrais documents : aucun faux en-tête tronqué. Produits par `generer.py` (reportlab, pypdf,
Pillow, python-docx) ; `executable.elf` est un exécutable Linux réel compilé par gcc. Contenus de fiction, aucune
donnée personnelle. Le seul fichier retouché à la main est `lettre_macro.docx` (un vrai DOCX + `word/vbaProject.bin`).
