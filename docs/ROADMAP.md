# Roadmap indicative — à revoir après audit

0. Audit lecture seule, cartographie ancien/nouveau, identification branche Rust/framework/auth/mobile, frontières production, consolidation documentaire.
1. Fondations : architecture confirmée, auth/permissions, multi-tenant, PostgreSQL dev, stockage privé, migrations contrôlées, tests et observabilité.
2. Administration, années, comptes/rôles, admissions, dossier élève/responsables, personnels, classes/groupes.
3. Cœur scolaire : EDT, évaluations/notes/bulletins, absences/appels/vie scolaire, messagerie/documents.
4. Gestion/services : facturation/paiements, restauration, internat, transports, séjours, tableaux de bord.
5. Applications Android/iOS MVP : terminer les usages ciblés par rôle déjà prévus.
6. Préparation pilote : charge, sécurité, RGPD, restauration, documentation et support.
7. Innovations : IA native, moteur documentaire, intégrations bureautiques et automatisations.

Pas de dates ni d'ordre rigide avant connaissance de l'existant. Les applications mobiles font partie du MVP, pas d'une phase facultative ultérieure.
