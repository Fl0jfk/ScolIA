# Vérification réglementaire des conceptions (socles 2 à 8 et personas)

Date de consultation de toutes les sources : **2026-11-09**. Documentation seulement, aucun code. Branche `ent-verif-reglementaire`.

## 1. Objet, méthode, limites

Les conceptions des socles 2 à 8 (`docs/socles/0[2-8]_*.md`) et les fichiers `PERSONAS_*` ont été écrits sans accès au réseau. Environ 370 mentions « de mémoire », « à vérifier », [NV] ou [H] y figurent ; celles qui portent sur une règle juridique ont été confrontées aux sources ci-dessous. Les mentions purement techniques ou commerciales (formats SIECLE, tarifs, logiciels du marché) ne sont pas traitées ici.

**Sources et niveau de confiance**

| Marque | Sens |
|---|---|
| **[V]** | Texte lu en entier sur la source citée. |
| **[V-ext]** | Lu seulement en extrait (moteur de recherche, copie non officielle, page résumée) : la règle est probable, la rédaction exacte reste à relire. |
| **[NT]** | Non trouvé : la conception garde [NV]. |

- **Codes français.** Légifrance, education.gouv.fr (BO) et eduscol renvoient 403 aux robots. Les articles de code ont été lus dans les **fichiers des données ouvertes de Légifrance republiés par codes.droit.org** (texte consolidé, dates de mise à jour : Code de l'éducation 2026-10-31, Code civil 2026-07-29, Code du patrimoine 2026-08-05, Code de la santé publique 2026-11-01, Code des postes et des communications électroniques 2026-08-19, Code du travail 2026-11-06, Code de commerce 2026-10-01). Ce n'est pas le site officiel. Le texte est celui de la DILA, mais **un juriste doit relire l'article sur Légifrance avant de coder une règle qui en dépend**. Adresse : `https://codes.droit.org/payloads/<nom du code>.xml`, par exemple https://codes.droit.org/payloads/Code%20de%20l%27%C3%A9ducation.xml.
- **RGPD** : texte reproduit par la CNIL (https://www.cnil.fr/fr/reglement-europeen-protection-donnees). **eIDAS** : version consolidée du 18-10-2024 publiée par l'Office des publications (https://publications.europa.eu/resource/celex/02014R0910-20241018.FRA.xhtml).
- Six recherches ont été menées en parallèle par des sous-agents. Les articles de code ci-dessous marqués [V] ont été relus par l'agent principal dans les fichiers cités.

**Ce que ce document n'est pas.** Il ne remplace ni l'avis d'un juriste ni celui du DPO. La colonne « Avis » dit **qui doit trancher**, sans trancher à sa place.

## 2. Tableau de synthèse
